# Happy birthday, Dad!

A ridiculous pixel birthday performance, with love from Travis, Trent and Trey.

**[Open the birthday card](https://cosmonautjones.github.io/happy-birthday-dad/)** and press **Start the show**.

One self-contained HTML file contains the hamster band, family characters, surprise guests, timed lyrics and playback controls. Audio starts only when you press play. Motion can be paused separately, and reduced-motion preferences are respected.

Look closely during the opening instrumental. Four lads from Liverpool may have taken a wrong turn.
